# 온기 🐾 유기동물 입양 찾기

공공데이터포털 **농림축산식품부 농림축산검역본부_국가동물보호정보시스템 구조동물 조회 서비스**(v2)를 이용해
전국 보호소의 구조동물을 찾아보는 웹앱입니다. (개인 과제용)

## 전체 구조
```
[GitHub Pages: HTML/CSS/JS]  ──찜·조회수·댓글·AI글──▶  [Firebase Realtime Database]
        │  (키 없이 요청)
        ▼
[Google Apps Script 웹 앱]  ── 인증키로 호출 ──▶  [공공데이터포털 구조동물 API]
   · 키 보관 (스크립트 속성)                    ──▶  [Gemini API]
   · 일괄 조회 / 캐시                             ──▶  [구글 시트: 알림 구독자]
   · 매일 9시 트리거 ── 새 공고 ──▶ [Gmail 알림]
```

## 페이지 구성 (6페이지)
| 파일 | 내용 |
|---|---|
| `index.html` | 구조동물 목록 · 필터 · 정렬 · 페이지네이션 · ♡ 찜 |
| `match.html` | 7문항 입양 성향 테스트 · 궁합 점수 추천 · 신규 공고 메일 알림 구독 |
| `detail.html` | 동물 상세 · 공고 기간 진행률 · ✨ AI 입양 홍보글 · 찜/조회수 · 공유/QR · 응원 댓글 · 같은 보호소의 다른 아이들 |
| `map.html` | 보호소 지도 (카카오맵 · 클러스터) · 내 위치에서 가까운 순 |
| `stats.html` | 보호 현황 통계 (KPI 4개 + Chart.js 차트 5개) |
| `favorites.html` | 내 찜 (최신 상태 자동 확인) · 인기 랭킹 (찜 수 · 조회수 TOP 10) |

## 사용한 API (JSON)
기본 주소: `https://apis.data.go.kr/1543061/abandonmentPublicService_v2`

| 기능 | 오퍼레이션 | 쓰이는 곳 |
|---|---|---|
| 시도 조회 | `sido_v2` | 시도 선택, 시도별 통계 |
| 시군구 조회 | `sigungu_v2` | 시도 선택 후 시군구 목록 |
| 보호소 조회 | `shelter_v2` | 시군구 선택 후 보호소 목록 |
| 품종 조회 | `kind_v2` | 축종 선택 후 품종 목록 |
| 구조동물 조회 | `abandonmentPublic_v2` | 목록, 상세(`desertion_no`), 같은 보호소(`care_reg_no`), 통계 건수 |
